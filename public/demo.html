Eagles chat widget — try it live

With npm run dev running, this page calls your local API at the same host as this script (so http://localhost:3000 and http://127.0.0.1:3000 both work). You need .env with ANTHROPIC_API_KEY, a valid ANTHROPIC_MODEL, and run npm run reindex once so data/eagles-index.json exists. If the API errors, the chat will show the error and then demo text.

Try it: click Chat (bottom-right) → type a question → Send. If the API is unavailable, the widget falls back to demo replies.

Example: "What is the Challenge program?" or "Where are you located?"

Brand: Orlando Eagles navy (#00213D), cyan (#63C9D6), white. Logo appears next to the title. Override with data-primary, data-accent, data-logo (or data-logo="none" to hide).
